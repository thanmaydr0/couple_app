# Us

An Android-only app for two people, built with Expo SDK 57, TypeScript and Expo Router.

Start with [DEV_LOOP.md](DEV_LOOP.md) for EAS project setup, cloud APK builds, phone testing and OTA updates. Email/password authentication, partner presence, the home dashboard, and profile/anniversary settings are implemented. Chat, memories, watch together, games, and calls have coming-soon screens; their feature implementations are still pending.

Standing collaboration and Git rules are in [AGENTS.md](AGENTS.md). Backend files in `supabase/` and `src/types/db.ts` belong to the backend session and are not part of the scaffold commit.
