# Us

An Android-only app scaffold for two people, built with Expo SDK 57, TypeScript and Expo Router.

Start with [DEV_LOOP.md](DEV_LOOP.md) for EAS project setup, cloud APK builds, phone testing and OTA updates. All feature screens currently render TODO placeholders.

Standing collaboration and Git rules are in [AGENTS.md](AGENTS.md). Backend files in `supabase/` and `src/types/db.ts` belong to the backend session and are not part of the scaffold commit.
